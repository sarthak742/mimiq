# Mimiq Architectural Laws

## The AMD Mandate

All vision models must route through the PRIMARY_VISION_* environment variables. Never hardcode API keys or default fallback URLs.

## The Aesthetic

Any generated UI must adhere to a Stealth Wealth aesthetic: high-contrast matte charcoal backgrounds, metallic accents, and premium minimalist typography.

## The Banned Commands

Never use sudo, rm -rf, or interact directly with C:\Windows\System32. Fallback to safe alternatives.

## The Project Goal

Mimiq watches local tutorial videos and extracts actionable steps using a vision-language model. It composes those steps around the user's goal, audits dependencies, and executes the resulting plan on the desktop with safety checks and visual verification. The primary demo path is reliable local `.mp4` upload through autonomous execution and HTML reporting, with cold web or YouTube processing treated only as later stretch work.
