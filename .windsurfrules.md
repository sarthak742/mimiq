# Mimiq Architectural Laws

## The AMD Mandate
All vision models must route through the `PRIMARY_VISION_*` environment variables. Never hardcode API keys or default fallback URLs.

## The Aesthetic
Any generated UI must adhere to a Stealth Wealth aesthetic: high-contrast matte charcoal backgrounds, metallic accents, and premium minimalist typography.

## The Banned Commands
Never use `sudo`, `rm -rf`, or interact directly with `C:\Windows\System32`. Fallback to safe alternatives.

## Component Responsibilities (CRITICAL)
* `orchestrator/lookahead.py` is strictly a transcript correction heuristic (checking for negation words).
* `utils/dependency_auditor.py` is the actual dependency scanner.
Never merge their responsibilities. They are completely separate tools.

## The Project Goal & Demo Priority
Mimiq watches local tutorial videos and extracts actionable steps using a vision-language model. It composes those steps around the user's goal, audits dependencies, and executes the resulting plan on the desktop. 
* **The primary demo path is reliable local `.mp4` upload.** 
* The cold YouTube pipeline is Day 5 stretch work only. Do not build or reference it until the local UI demo is fully green.
